# Oracle two-level

Внутренний критик первого уровня — косинусная награда оракула
`r_int = (1 - gamma1) * cos(предсказание, s' - s)` при `gamma_restoration = 0`.
Отдельного критика на `(1 - gamma1) * V2` нет. К этому можно вернуться.

Advantage опции при обратном проходе обрезается по смене индекса опции.
Опция из k шагов получает k слагаемых `r2 = V_ext * (1 - gamma1)`.
Этот advantage учит `V2` и `-log π2`. `-log π1` учится от внутреннего критика.
Внешний advantage умножает только лосс декодера.
